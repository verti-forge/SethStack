# Stack Guides

In-depth, practical instruments for **Angle stacks** and **Distinction families**. Not chapter digests. Not Concept essays. Not lifestyle coaching.

Chapter digests remember what a chapter did. Findings hold compressed boards. **Stack guides** hold reusable leverage: how a multi-pass claim stays sound, how it fails, and how to pressure-test later text.

YAML remains the curation notebook / train of thought / graph source. Stack guides are a handoff deliverable beside findings and digests.

## Promotion rule

Write or update a stack guide when **either**:

1. An Angle stack has **≥3 protected passes** across chapters, or  
2. The stack is listed under **Angle stacks to protect** in `docs-ops/FRAMEWORK_SOUNDNESS.md`

Do **not** promote every Concept into a guide. Cap the set to stacks that carry framework-soundness load.

## Guide voice

- Paragraph prose (Field Guide / digest family)
- Roughly 1500–2500 words for a full guide; shorter updates OK
- Cite real YAML ids
- Pressure tests for reading/extraction — not manifestation drills
- Adjacent frameworks = echoes only
